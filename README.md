# Cryptography Algorithms Implementation

## Overview
This project demonstrates basic cryptography concepts using Python.

The program performs:
- AES Encryption
- AES Decryption
- SHA-256 Hashing

## Technologies Used
- Python
- PyCryptodome

## Features
- Secure encryption using AES algorithm
- Data decryption using secret key
- SHA-256 hash generation for integrity verification

## Learning Outcome
This project helped in understanding:
- Encryption and decryption
- Hashing algorithms
- Basic cybersecurity concepts
